# SyncroSim Chart class

`Chart` object representing a SyncroSim Chart object. A Chart object is
used to create line or column charts from tabular output data in the and
can be viewed using the SyncroSim User Interface.

## Slots

- `session`:

  `Session` object. The Session associated with the Chart's SsimLibrary

- `filepath`:

  character string. The path to the Chart's SsimLibrary on disk

- `chartId`:

  integer. The Chart id

- `projectId`:

  integer. The Project id

## See also

See [`chart`](https://syncrosim.github.io/rsyncrosim/reference/chart.md)
for options when creating or loading a SyncroSim Chart
