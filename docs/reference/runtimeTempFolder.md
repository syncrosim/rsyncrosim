# SyncroSim Temporary Folder

This function is part of a set of functions designed to facilitate the
development of R-based Syncrosim Packages. This function creates and
returns a SyncroSim Temporary Folder.

## Usage

``` r
runtimeTempFolder(folderName)
```

## Arguments

- folderName:

  character. The folder name

## Value

Returns a temporary folder name.

## Examples

``` r
if (FALSE) { # \dontrun{
tempFolder <- runtimeTempFolder()
} # }
```
